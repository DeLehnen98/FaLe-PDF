## Full description (≤ 4000)

```
FaLe PDF는 휴대폰과 태블릿에서 쓰는 나만의 오피스입니다. PDF를 읽고, 작성하고, 서명하고, 스캔하고, 편집할 수 있으며 문서, 스프레드시트, 프레젠테이션도 다룰 수 있습니다. 프로 기능도 모두 포함되어 있으며 구독도, 계정도, 워터마크도 필요 없습니다. 파일은 기기에서 처리됩니다. 원하면 FaLe 계정으로 내 기기 간에 종단간 암호화된 상태로 동기화할 수 있습니다.

PDF 읽기
• 빠른 PDF 뷰어: 검색, 북마크, 목차
• 읽기 모드: 휴대폰 화면에 맞게 텍스트를 다시 배치하고, 글꼴 크기 조절, 세피아, 다크 모드 지원
• 소리 내어 읽기(기기의 음성 출력 사용)

작성 및 서명
• PDF 양식 작성
• 서명을 직접 그려 저장하고 한 번의 탭으로 삽입
• 날짜, 텍스트, 이니셜, 나만의 도장

텍스트 인식 스캔
• 카메라 스캐너: 가장자리 감지, 페이지 보정, 대비 개선
• 기기에서 텍스트 인식(OCR), 오프라인에서도 가능: 스캔한 문서를 검색할 수 있게 변환
• 사진 속 텍스트 복사, 이미지를 DOCX 또는 XLSX로 변환
• 신분증, 명함, 여권 사진, QR 코드

주석 및 편집
• 형광펜, 메모, 손글씨, 도형
• 텍스트와 이미지 추가 또는 교체
• 가리기: 기밀 내용을 완전히 삭제
• 워터마크, 페이지 번호, 머리글 및 바닥글

페이지와 파일
• 페이지 합치기, 순서 변경, 회전, 추출, 자르기
• PDF 압축, 일괄 처리
• 비밀번호 보호(AES-256) 설정 및 제거
• 두 PDF 버전 비교
• 추가 도구 40가지: PDF/A, 레터헤드, 소책자, 한 장에 여러 페이지, PDF 복구, 배경 제거

변환
• PDF를 DOCX, XLSX, PPTX로 변환하고 다시 PDF로도 변환
• 이미지를 PDF로, 페이지를 이미지나 텍스트로 내보내기

문서, 스프레드시트, 프레젠테이션
• DOCX, XLSX, PPTX 열기, 편집, 새로 만들기
• 수식과 차트를 지원하는 스프레드시트
• 약 100가지 템플릿: 이력서, 청구서, 달력, 상품권, 계약서, 슬라이드 디자인
• 갑자기 종료되어도 안전하며, 원하면 원본 파일에 바로 저장
• 독일용 서신 생성기(해지, 철회, 이의 제기 – 서신은 독일어로 작성되며 독일에서 쓰는 용도입니다)

일상에서
• 기한 및 알림: 통지 기간을 놓치지 않도록
• 나만의 PIN으로 보호되는 개인 보관함
• '다른 앱으로 열기'와 '공유': 이메일, 메신저, 파일 관리자의 파일을 바로 가져오기
• 저장한 파일은 '문서/FaLe PDF' 폴더에 보관됩니다

공유, 서명 받기, 전송
• 안전하게 공유: 종단간 암호화된 링크가 자동으로 만료됩니다(1시간~7일). 비밀번호와 다운로드 횟수 제한은 선택 사항
• 서명 요청: 서명란을 배치하고 메신저나 이메일로 링크를 보내세요. 상대방은 계정 없이 브라우저에서 서명하며 감사 기록 페이지가 함께 제공됩니다(단순 전자서명)
• 기기 연결: QR 코드로 휴대폰과 PC 간에 파일을 직접, 암호화하여 전송

AI 도우미(선택 사항)
• 문서와 대화: 질문하면 페이지 출처가 포함된 답변을 받을 수 있습니다
• 요약, 번역, 글쓰기 도움, 수식 도우미, AI 슬라이드
• 메모로 학습 카드와 퀴즈 만들기, AI 편지 작성, 사진 번역
• 계정 없이 매일 일정 횟수가 포함되어 있습니다. 더 쓰려면 선택형 동영상 광고 시청 또는 FaLe Plus
• AI가 필요 없나요? 스위치 하나로 완전히 숨길 수 있습니다
• 동의하신 경우에만 사용되며, 선택한 텍스트만 전송됩니다. AI 답변에는 오류가 있을 수 있습니다. 문제가 있는 답변은 이메일로 알려 주세요.

구독 함정 없이 공정하게
• 구독으로 바뀌는 체험판도, 저장할 때 뜨는 팝업도 없습니다
• FaLe Plus는 구독 또는 한 번 결제로 평생 이용 – 탭 한 번으로 해지, 갱신 전마다 미리 알림

설계부터 개인정보 보호
계정 불필요, 배너 광고 없음, 분석 도구 없음. 선택 사항인 FaLe 계정: FaLe Sync(종단간 암호화, 서버는 프랑크푸르트에 있으며 내용은 아무것도 읽을 수 없습니다)와 모든 기기에서 사용하는 FaLe Plus. 광고는 AI 추가 이용 횟수를 얻으려고 직접 동영상을 재생할 때만 표시됩니다. 카메라는 스캔에만, 알림은 직접 설정한 알림에만 사용합니다. 클라우드 AI, 공유, 전송을 제외한 모든 기능은 오프라인에서 작동합니다. 공유한 파일은 종단간 암호화되어 저희도 읽을 수 없습니다.

내 언어로 사용: 앱이 휴대폰 언어를 자동으로 따릅니다. 워터마크도 없습니다. 선택 사항: FaLe Plus로 AI를 더 많이 이용하세요.
```

## Feature bullets

- 모든 프로 기능 포함 – 구독 없음, 계정 없음, 워터마크 없음
- PDF 작성 및 서명
- 가장자리 감지와 오프라인 텍스트 인식(OCR) 스캔
- AI 도우미: 문서에 질문하고 페이지 출처가 포함된 답변 받기(선택 사항)
- 안전한 공유와 서명 요청 – 종단간 암호화, 계정 불필요
- 휴대폰 ↔ PC: QR 코드로 파일 전송
- 선택 사항: FaLe Sync – 모든 기기에서 종단간 암호화
- 문서, 스프레드시트, 프레젠테이션 편집
- PDF ↔ DOCX, XLSX, PPTX 변환
- 기한, 알림, 개인 보관함
- 파일은 내 기기에만 보관됩니다
