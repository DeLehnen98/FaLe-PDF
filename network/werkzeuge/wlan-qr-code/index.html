WLAN-QR-Code erstellen

Netzwerkname und Passwort eintragen – daraus wird ein QR-Code und auf Wunsch eine Karte zum Aufstellen.

Du brauchst einen QR-Code für einen Link, Kontakt oder Text? QR-Code erstellen

  • Bleibt auf deinem Gerät
  • Ohne Limits
  • Ohne Wasserzeichen
  • Ohne Konto
Wie prüfe ich, dass nichts hochgeladen wird?

Deine Dateien werden in diesem Browser-Tab verarbeitet. Diese Seite hat keine Funktion, die Dateien an einen Server schickt, und ihre Sicherheitsregeln (Content Security Policy) verbieten Verbindungen zu fremden Servern.

So prüfst du es selbst: Lade diese Seite, schalte dann den Flugmodus ein oder trenne das WLAN und starte das Werkzeug. Es funktioniert trotzdem – weil alles auf deinem Gerät passiert.

Gut zu wissen

So geht’s – Schritt für Schritt

  1. WLAN eintragen

    Gib den Netzwerknamen (SSID) genau so ein, wie er im Handy erscheint, dazu das Passwort und die Verschlüsselung – meist WPA.

  2. Karte oder Bild wählen

    Die Karte (PDF) enthält Code, Netzwerkname und Passwort zum Ausdrucken – einzeln in A6 oder vier Stück auf A4. Als PNG schickst du den Code per Messenger.

  3. Speichern und testen

    Speichere die Datei und scanne den Code einmal mit dem Handy, bevor du die Karte aufstellst.

Warum mit FaLe?

  • Karte mit Klartext

    Laptop, Fernseher oder Konsole können oft nicht scannen. Deshalb stehen Netzwerkname und Passwort auf der Karte auch lesbar – in einer Schrift, in der man l, 1, O und 0 unterscheiden kann.

  • Sonderzeichen sicher

    Zeichen wie ; , : oder Anführungszeichen im Netzwerknamen oder Passwort brechen bei manchen Generatoren den Code. FaLe maskiert sie korrekt und liest jeden Code zur Kontrolle wieder aus.

  • Dein Passwort bleibt bei dir

    Der Code entsteht im Browser. Netzwerkname und Passwort werden nicht übertragen und nicht gespeichert.

Häufige Fragen
Funktioniert der WLAN-QR-Code mit iPhone und Android?

Ja. Aktuelle iPhones und Android-Handys erkennen WLAN-Codes direkt in der Kamera-App und bieten an, sich zu verbinden.

Was mache ich, wenn das Verbinden nicht klappt?

Meist stimmt der Netzwerkname nicht genau – Groß- und Kleinschreibung und Leerzeichen zählen. Prüfe auch die Verschlüsselung: Für WPA2 und WPA3 wählst du „WPA“.

Ändert sich der Code, wenn ich das Passwort ändere?

Ja. Das Passwort steht im Code selbst. Nach einer Änderung erstellst du einfach eine neue Karte.

Ist es sicher, das Passwort als QR-Code aufzuhängen?

Jeder, der den Code scannt, kann das Passwort lesen. Häng ihn deshalb nur dort auf, wo du das Passwort auch so verraten würdest – ideal ist ein eigenes Gastnetz deines Routers.

Was ist ein verstecktes Netzwerk?

Ein WLAN, dessen Name nicht in der Liste erscheint. Setz den Haken nur, wenn dein Router den Namen wirklich verbirgt – sonst kann das Verbinden länger dauern.
