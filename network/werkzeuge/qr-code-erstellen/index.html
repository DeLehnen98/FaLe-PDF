QR-Code erstellen

Erstelle QR-Codes für Link, WLAN oder Kontakt – mit Live-Vorschau und Selbsttest.

  • Bleibt auf deinem Gerät
  • Ohne Limits
  • Ohne Wasserzeichen
  • Ohne Konto
Wie prüfe ich, dass nichts hochgeladen wird?

Deine Dateien werden in diesem Browser-Tab verarbeitet. Diese Seite hat keine Funktion, die Dateien an einen Server schickt, und ihre Sicherheitsregeln (Content Security Policy) verbieten Verbindungen zu fremden Servern.

So prüfst du es selbst: Lade diese Seite, schalte dann den Flugmodus ein oder trenne das WLAN und starte das Werkzeug. Es funktioniert trotzdem – weil alles auf deinem Gerät passiert.

So geht’s

  1. Inhalt wählen

    Wähle, was in den Code soll – Link, Text, WLAN-Zugang, Kontakt, E-Mail, Telefon, SMS oder einen Ort – und füll die Felder aus.

  2. Gestalten

    Passe Farben, Rand und Fehlerkorrektur an. Die Vorschau zeigt sofort das Ergebnis und prüft, ob der Code lesbar bleibt.

  3. Speichern

    Speichere den Code als PNG für Handy und Web, als SVG für Grafikprogramme oder als PDF zum Drucken.

Warum mit FaLe?

  • Mit Selbsttest

    FaLe liest jeden erzeugten Code wieder aus und vergleicht ihn mit deinem Inhalt. Zu wenig Kontrast oder ein zu schmaler Rand werden angemahnt.

  • Für alle Fälle

    Link, Text, WLAN mit Passwort, Kontaktkarte, E-Mail, Telefon, SMS und Ort – ohne dass du das Format dafür kennen musst.

  • Läuft nie ab

    Der Inhalt steht direkt im Code. Es gibt keine Weiterleitung über fremde Server, die irgendwann abgeschaltet oder kostenpflichtig wird.

  • Gestochen scharf

    PNG bis 4096 px, SVG und PDF als Vektor – scharf auf Flyer, Plakat und Visitenkarte.

Häufige Fragen

Ist der QR-Code dauerhaft gültig?

Ja. Der Inhalt steht direkt im Code, ohne Umweg über einen Kurzlink-Dienst. Er funktioniert so lange, wie der Link oder die Daten darin stimmen.

Werden meine Daten irgendwo gespeichert?

Nein. Der Code entsteht in deinem Browser. WLAN-Passwörter und Kontaktdaten verlassen dein Gerät nicht.

Wie mache ich einen QR-Code für mein WLAN?

Wähle „WLAN“, gib Netzwerkname und Passwort ein und wähle die Verschlüsselung (meist WPA). Gäste scannen den Code mit der Kamera und verbinden sich ohne Abtippen.

Welche Farben kann ich nehmen?

Jede, solange der Code deutlich dunkler ist als der Hintergrund. Helle Codes auf dunklem Grund lesen viele Scanner nicht – dann warnt FaLe dich.

Welche Fehlerkorrektur brauche ich?

M passt meistens. Wird der Code gedruckt und kann verschmutzen oder knicken, nimm Q oder H. Höhere Stufen machen den Code dichter.

Wie groß muss ich ihn drucken?

Je mehr Inhalt, desto feiner das Muster und desto größer sollte der Druck sein. Teste den Ausdruck am besten mit deinem Handy aus der Entfernung, aus der später gescannt wird.
