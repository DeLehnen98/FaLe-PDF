PDF bearbeiten

Text in PDF einfügen, Haken setzen, markieren – direkt auf der Seite, per Fingertipp.

Wie prüfe ich, dass nichts hochgeladen wird?

Deine Dateien werden in diesem Browser-Tab verarbeitet. Diese Seite hat keine Funktion, die Dateien an einen Server schickt, und ihre Sicherheitsregeln (Content Security Policy) verbieten Verbindungen zu fremden Servern.

So prüfst du es selbst: Lade diese Seite, schalte dann den Flugmodus ein oder trenne das WLAN und starte das Werkzeug. Es funktioniert trotzdem – weil alles auf deinem Gerät passiert.

Gut zu wissen

So geht’s – Schritt für Schritt

  1. PDF auswählen

    Wähle die PDF aus, die du bearbeiten möchtest – ein Formular, einen Vertrag, ein Arbeitsblatt.

  2. Auf der Seite bearbeiten

    Wähle oben ein Werkzeug und tippe auf die Seite: Text, Haken, Datum oder Markierung. Ziehe Elemente mit dem Finger an ihren Platz und ändere die Größe an den Griffen. Mit „Rückgängig“ machst du jeden Schritt ungeschehen.

  3. Speichern

    Tippe auf „Speichern“. Deine Änderungen werden fest in die PDF geschrieben – du kannst sie herunterladen oder direkt teilen.

Warum mit FaLe?

  • Fürs Handy gebaut

    Große Werkzeugknöpfe, Elemente mit dem Finger verschieben, Griffe zum Vergrößern und eine Zoom-Taste für kleine Kästchen. Haken tippst du einfach an – ein zweiter Tipp entfernt ihn wieder.

  • Text ändern

    Tippe auf eine vorhandene Zeile: Sie wird weiß abgedeckt und als bearbeitbarer Text darübergelegt – in ähnlicher Größe und Schrift. Ideal für Tippfehler, Daten und Adressen.

  • Markieren, das auf Text einrastet

    Ziehe den Marker über Text, und die Markierung folgt den Zeilen genau. Auf Scans ziehst du einfach einen Bereich auf.

  • Echter Text, echte Vektoren

    Dein Text bleibt markier- und durchsuchbar, Formen und Haken bleiben beim Zoomen scharf. Die Seiten werden nicht in Bilder umgewandelt.

Häufige Fragen
Werden meine Dateien hochgeladen?

Nein. Du bearbeitest die PDF vollständig in deinem Browser. Gerade bei Verträgen und Formularen mit persönlichen Daten bleibt so alles auf deinem Gerät.

Kann ich vorhandenen Text direkt ändern?

Mit „Text ändern“ tippst du eine Zeile an: Sie wird weiß abgedeckt und du schreibst den neuen Text darüber. Der ursprüngliche Text bleibt dabei unter der Abdeckung in der Datei. Die Schrift wird so ähnlich wie möglich gewählt, kann aber leicht abweichen.

Ist „Abdecken“ sicheres Schwärzen?

Nein. Abdecken legt nur einen Kasten über den Inhalt – darunter bleibt er in der Datei erhalten und kann herauskopiert werden. Für vertrauliche Daten brauchst du ein echtes Schwärzen-Werkzeug.

Welche Zeichen kann ich schreiben?

Die eingebauten PDF-Schriften decken westeuropäische Zeichen ab, also auch ä, ö, ü, ß und €. Andere Zeichen werden ersetzt – das Werkzeug zeigt dir beim Tippen, welche.

Kann ich mehrere Seiten bearbeiten?

Ja. Blättere mit den Pfeilen oder wische auf freier Fläche zur nächsten Seite. Alle Änderungen auf allen Seiten werden zusammen gespeichert.

Sind die Änderungen später noch bearbeitbar?

Sie werden fest in die Seite geschrieben, damit sie in jedem Programm gleich aussehen. Willst du später noch etwas ändern, bearbeite am besten wieder die ursprüngliche Datei.
