QR-Code scannen

Lies QR-Codes mit der Kamera, aus einem Screenshot oder einer PDF – und sieh vor dem Öffnen, wohin ein Link wirklich führt.

  • Bleibt auf deinem Gerät
  • Ohne Limits
  • Ohne Wasserzeichen
  • Ohne Konto
Wie prüfe ich, dass nichts hochgeladen wird?

Deine Dateien werden in diesem Browser-Tab verarbeitet. Diese Seite hat keine Funktion, die Dateien an einen Server schickt, und ihre Sicherheitsregeln (Content Security Policy) verbieten Verbindungen zu fremden Servern.

So prüfst du es selbst: Lade diese Seite, schalte dann den Flugmodus ein oder trenne das WLAN und starte das Werkzeug. Es funktioniert trotzdem – weil alles auf deinem Gerät passiert.

Gut zu wissen

So geht’s – Schritt für Schritt

  1. Kamera starten oder Bild wählen

    Tippe auf „Kamera starten“ und erlaube den Zugriff – oder wähle ein Foto, einen Screenshot oder eine PDF mit dem Code. Ziehen und Einfügen mit Strg+V geht auch.

  2. Code ins Bild halten

    Halte den Code ruhig in den Rahmen. Bei schwachem Licht hilft die Lampe, bei kleinen Codes der Zoom. Sobald der Code erkannt ist, piept es kurz.

  3. Prüfen und entscheiden

    Du siehst, was im Code steckt: Link mit echtem Ziel und Warnzeichen, WLAN-Zugang, Kontakt, Termin oder Überweisung. Erst dein Tipp öffnet, kopiert oder speichert etwas.

Warum mit FaLe?

  • Schutz vor QR-Betrug

    Links öffnen nie automatisch. Du siehst die echte Domain und Warnzeichen wie Kurzlinks, nachgemachte Buchstaben, getarnte Adressen oder App-Downloads.

  • Versteht, was drinsteht

    WLAN-Passwort zum Kopieren, Kontakt als Datei, Termin für den Kalender, Überweisungscode mit geprüfter IBAN – statt eines unverständlichen Textes.

  • Keine App, keine Werbung

    Läuft im Browser, auch offline nach dem ersten Laden. Nichts wird hochgeladen; der Verlauf bleibt auf deinem Gerät und lässt sich jederzeit löschen.

  • Auch aus Bildern und PDFs

    Codes auf Rechnungen, in Screenshots oder in eingescannten Briefen werden direkt aus der Datei gelesen – praktisch, wenn der Code auf demselben Handy angezeigt wird.

Häufige Fragen
Kann ich einen QR-Code ohne App scannen?

Ja. Diese Seite nutzt die Kamera direkt im Browser. Wenn dein Browser keinen Kamerazugriff erlaubt, nimm ein Foto vom Code auf oder wähle ein Bild – das Ergebnis ist dasselbe.

Woran erkenne ich einen gefährlichen QR-Code?

Achte auf die Domain direkt vor der Endung, etwa „beispiel.de“. Warnzeichen sind Kurzlinks, ungewöhnliche Endungen, Buchstaben aus anderen Alphabeten, ein „@“ in der Adresse und Links, die direkt eine App herunterladen. Die Seite zeigt dir all das vor dem Öffnen – eine Garantie ist es trotzdem nicht.

Was ist Quishing?

Quishing ist Betrug mit QR-Codes: Gefälschte Codes auf Parkautomaten, Ladesäulen, Plakaten oder in Briefen führen auf nachgemachte Seiten, die Zugangsdaten oder Zahlungen abgreifen. Prüf deshalb immer das Ziel und achte auf überklebte Codes.

Werden meine Scans gespeichert oder gesendet?

Nichts wird gesendet: Kamerabild und Dateien werden nur auf deinem Gerät ausgewertet. Der Verlauf liegt nur in diesem Browser, lässt sich abschalten und löschen. Zwei-Faktor-Schlüssel werden nie gespeichert.

Kann ich einen QR-Code aus einem Screenshot oder einer PDF lesen?

Ja. Wähle das Bild oder die PDF aus, zieh die Datei auf die Seite oder füge einen Screenshot mit Strg+V ein. Bei PDFs werden alle Seiten durchsucht – auch mehrere Codes auf einer Seite.

Welche Codes werden erkannt?

QR-Codes immer, auch gedreht, schräg oder als helle Codes auf dunklem Grund. Wenn dein Browser einen eingebauten Barcode-Leser hat, erkennt die Seite zusätzlich Strichcodes wie EAN und Code 128 sowie Data-Matrix-Codes.
