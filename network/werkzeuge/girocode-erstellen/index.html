Wie prüfe ich, dass nichts hochgeladen wird?

Deine Dateien werden in diesem Browser-Tab verarbeitet. Diese Seite hat keine Funktion, die Dateien an einen Server schickt, und ihre Sicherheitsregeln (Content Security Policy) verbieten Verbindungen zu fremden Servern.

So prüfst du es selbst: Lade diese Seite, schalte dann den Flugmodus ein oder trenne das WLAN und starte das Werkzeug. Es funktioniert trotzdem – weil alles auf deinem Gerät passiert.

Gut zu wissen

So geht’s – Schritt für Schritt

  1. Daten eintragen

    Gib den Kontoinhaber und die IBAN ein. Betrag und Verwendungszweck sind optional – ohne Betrag trägt ihn der Zahlende selbst ein.

  2. Format wählen

    PNG für Rechnung, Website oder Messenger, SVG oder PDF für den Druck – oder die Karte mit allen Angaben im Klartext, etwa für die Kasse beim Vereinsfest.

  3. Speichern und testen

    Speichere den Code und scanne ihn einmal mit deiner Banking-App. Abschicken musst du die Überweisung dabei nicht.

Warum mit FaLe?

  • IBAN wird geprüft

    Ein Zahlendreher in der IBAN fällt sofort auf, bevor der Code gedruckt ist – über die Prüfziffer, wie bei der Bank.

  • Nach Standard

    Der Code folgt der EPC-Vorgabe (Version 002): BIC optional, Name bis 70 und Verwendungszweck bis 140 Zeichen, Betrag bis 999.999.999,99 €. Zu lange Angaben werden gekürzt statt den Code zu zerstören.

  • Kein Abo, kein Ablauf

    Die Überweisungsdaten stehen direkt im Code. Er funktioniert ohne Umweg über einen fremden Server und läuft nie ab.

  • Bleibt auf deinem Gerät

    IBAN und Name werden nicht hochgeladen und nicht gespeichert.

Häufige Fragen
Welche Banking-Apps können GiroCodes lesen?

Die meisten Banking-Apps in Deutschland, Österreich und vielen anderen Euro-Ländern – oft unter „Scannen“, „Foto-Überweisung“ oder „Scan2Bank“. Die Überweisung wird nur ausgefüllt, abschicken muss sie der Zahlende selbst.

Brauche ich die BIC?

Für Überweisungen im SEPA-Raum nicht. Lass das Feld leer, wenn du sie nicht kennst.

Kann ich einen GiroCode ohne Betrag erstellen?

Ja. Dann trägt der Zahlende den Betrag selbst ein – praktisch für Spenden oder Trinkgeld.

Darf ich Umlaute im Verwendungszweck verwenden?

Der Code selbst kann Umlaute enthalten. Manche Banken wandeln sie bei der Überweisung um, etwa ä in ae. Für Rechnungsnummern sind Buchstaben, Ziffern und Bindestriche am sichersten.

Ist ein GiroCode sicher?

Er enthält nur, was auch auf einem Überweisungsträger stünde. Der Zahlende sieht vor dem Absenden alle Daten in seiner App. Prüfe aufgeklebte Codes an fremden Orten trotzdem, bevor du bezahlst.
