Send files securely – no account

Pick a file, send the link. It is encrypted on your device – only people with the link can open it.

Runs in FaLe PDF in your browser. Nothing to install, no account – not even for the recipient.

How it works

  1. Pick a file

    Any kind of file up to 50 MB – PDFs, photos, videos, spreadsheets or a ZIP archive.

  2. Set it up

    Choose how long the link is valid (1 hour, 1 day or 7 days) and how often the file may be downloaded. Optionally with a password.

  3. Send the link

    Via messenger, email or QR code. The recipient opens the link in a browser and downloads the file – no sign-up.

What you get

  • End-to-end encryptedThe file is encrypted before it leaves your device. The key is only in the link – our server cannot read it.
  • No account, no adsNeither you nor the recipient need to sign up. No ads, no tracking.
  • You set the rulesExpiry, download limit and password – and you can delete the link yourself at any time.
  • Deletes itselfWhen it expires or the download limit is reached, the file is deleted from the server automatically.

Frequently asked questions

How big can a file be?

Up to 50 MB per file. Put several files into a ZIP archive first.

What does it cost?

Nothing. Sending is free and without ads.

Who can see my file?

Only people with the link (and the password, if you set one). The key is in the part of the link after the #, which is never sent to our server.

How long is the file stored?

As long as you choose: 1 hour, 1 day or at most 7 days – or until the download limit is reached. Then it is deleted automatically.

Does the recipient need an app?

No. The link opens in any current browser on a phone or computer.

And between my own devices?

FaLe PDF has “Connect devices”: scan a QR code and send files straight from your phone to your PC.
