Frequently asked questions

Do the formulas work in other programs?

Yes. The file is a normal Excel file (XLSX) with real formulas. Every template is checked in a free spreadsheet program that recalculates the formulas. Drop-down lists and colour rules are stored in the file as well.

Is anything I type stored?

No. Preview, editing and download all happen in your browser. There is no account and nothing is uploaded. Download the file before you close the page.

Why are the labels in German?

The templates were made for everyday use in Germany – things like the mileage log, the club cash report or the profit-and-loss sheet follow German practice. Formulas and numbers work the same in any language version of your spreadsheet program.
