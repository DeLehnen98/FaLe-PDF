FaLe CleanComing soon

Clean up Windows without the scare tactics.

FaLe Clean is a system cleaner for Windows 10 and 11, written from scratch. It shows you exactly what will be deleted, skips the alarmist language and lets you undo much of what it does.

Not available for download yet. FaLe Clean is running on test PCs right now. As soon as a version is stable enough, it will appear here – with installation instructions.

What FaLe Clean is meant to do

The planned feature set, as it exists in the current test version. Things may still change before launch.

  • Health check

    • Scores your PC from 0 to 100 – with honest recommendations instead of alarms
    • Battery health from the Windows battery report, SSD and hard drive condition
    • Antivirus, firewall and pending restarts at a glance

  • Cleanup

    • Temp files, browser caches (Chrome, Edge, Brave, Opera, Vivaldi, Firefox), shader cache, crash dumps
    • Click a row to see exactly which files will be deleted
    • Keep cookies for chosen sites so you stay signed in

  • Understand your storage

    • Largest folders, file types and the 100 largest files
    • Find duplicate files by comparing contents – they go to the Recycle Bin
    • Spot old installers in your Downloads folder

  • Faster startup

    • Your PC’s real boot time from the Windows Event Viewer
    • For each startup entry: how many seconds it delays startup according to Windows
    • Performance mode and gaming mode that put everything back afterwards

  • Programs & updates

    • Uninstall programs, then look for leftovers
    • Find and update outdated programs via winget

  • Privacy & automation

    • Turn off Windows ads, Bing search, Copilot, Recall and telemetry – reversible
    • Remove preinstalled apps such as Candy Crush or TikTok
    • Scheduled cleanup via Windows Task Scheduler

Whether any features will be part of FaLe Plus later is something we will decide before launch – and state openly here.

Safe, not radical

Careful rules
Temp files are only deleted once they are older than two hours. Your user folder, Windows and Program Files are never emptied recursively.
Undo
History, cookies, old installers and program leftovers stay in quarantine for 7 days and can be restored with one click. Duplicates go to the Recycle Bin.
No surprises
If a browser is open while cleaning, FaLe Clean asks before closing it. No pop-ups and no ads in the app.
Stays on your PC
The interface only runs locally on your computer and is protected by a random token. FaLe Clean only uses what Windows already includes.

Deliberately left out

Registry cleaner
According to Microsoft it brings no measurable benefit and can damage Windows.
Own driver database
Vetted drivers come through Windows Update under “Optional updates”.

Requirements

System
Windows 10 or 11
Languages
English and German, follows your Windows display language
Test version
Runs on the official, signed Python from python.org – so Windows Smart App Control doesn’t block it. How the final version installs will be explained here at launch.
