FaLe PDF

Use FaLe PDF in your organisation.

Documents stay on the workstations. Your IT deploys FaLe PDF with Microsoft Edge or Google Chrome policies and can switch off everything that goes over the internet.

Open FaLe PDF (opens in a new tab)

What privacy officers and IT want to know

Processing on the device
Viewing, filling in, signing, redacting, text recognition, compressing and converting run in the browser on each PC. No documents are uploaded to our servers.
No account, no licence keys
No sign-in and no user management – FaLe PDF starts right away on every workstation.
Works offline
After the first start, FaLe PDF also works without an internet connection.
Online only on request
Only three features use the internet: cloud AI (only with consent), letters by post and fax, and encrypted sharing. Each can be switched off centrally (see below).
No tracking
No analytics tools and no ad banners – details in the privacy policy.
Where files are kept
In FaLe PDF’s file list in each person’s browser profile. “Save” writes results as normal files to any folder, including network drives.

How to deploy FaLe PDF

No installer package needed: Microsoft Edge and Google Chrome install FaLe PDF on every PC through a policy (Group Policy, Intune or any other MDM). The policies apply to Windows and macOS.

  1. Install on every PC

    Set the policy WebAppInstallForceList (Edge: “Configure list of force-installed Web Apps”) to this value. FaLe PDF then appears as its own program in the Start menu and on the desktop.

    [{"url": "https://pdf.fale.network/app/", "default_launch_container": "window", "create_desktop_shortcut": true}]

  2. Switch off online features (optional)

    Put this file on a server of your own (for example the intranet). false switches a feature off: cloudAi = cloud AI, post = letters by post and fax, cloudShare = encrypted sharing and transfers. Under “Me”, people then see the note “Set by your organisation”.

    { "cloudAi": false, "post": false, "cloudShare": false }

  3. Connect the file to FaLe PDF

    Set the policy ManagedConfigurationPerOrigin to the address of the file. It only applies to web apps installed as in step 1. Change the hash whenever the file changes.

    [{"origin": "https://pdf.fale.network", "managed_configuration_url": "https://intranet.example.com/fale-pdf.json", "managed_configuration_hash": "<SHA-256 of the file>"}]

  4. Open PDFs with a double-click

    After installation, FaLe PDF is offered under “Open with”. Make it the default app for PDFs in the Windows settings under “Default apps”.

E-invoices

FaLe PDF opens XRechnung and ZUGFeRD invoices and shows them in readable form – offline. Tools add their result as a new file to the file list; the invoice itself stays there as it was. For record keeping: archive the original invoice with its invoice data (XML) unchanged.

Common questions from IT

How are updates delivered?

Like any web app: on the next start FaLe PDF loads the new version in the background. There is no installer that overwrites settings.

Does FaLe PDF run on terminal servers and Citrix?

FaLe PDF runs wherever a current Edge or Chrome runs. FaLe PDF’s file list lives in the person’s browser profile on that machine; documents that must be available on every workstation are saved to a network drive as usual.

Which browsers are supported?

Current versions of Microsoft Edge and Google Chrome; central deployment through policies works with these two. Firefox and Safari open FaLe PDF too.

Is FaLe PDF in the Microsoft Store?

Soon. Until then, individuals install FaLe PDF straight from the browser and organisations use the policy above.
