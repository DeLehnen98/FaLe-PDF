Create a barcode

Create EAN, UPC, Code 128, Code 39 or ITF-14 barcodes – with check digit and self-test.

  • Stays on your device
  • No limits
  • No watermark

How can I check that nothing is uploaded?

Your files are processed in this browser tab. This page has no function that sends files to a server, and its security rules (Content Security Policy) forbid connections to other servers.

Check it yourself: load this page, then switch on flight mode or disconnect Wi-Fi and run the tool. It still works – because everything happens on your device.

Good to know

How it works – step by step

  1. Type and content

    Choose the barcode type and enter the number or text. For EAN, UPC and ITF-14 the check digit is added or checked.

  2. Size and colour

    Set bar width and height in millimetres, turn the human-readable text on or off and choose the colours. The preview checks right away that the code is readable.

  3. Save

    Save the barcode as PNG for office and labels, as SVG for design programs or as PDF for printing.

Why FaLe?

  • With check digit

    The check digit is calculated by the GS1 rule. If you enter the full number, we tell you whether it is right – and which digit would be.

  • Self-test

    Every barcode is read back after it is created. The test only passes if it reads exactly as your content.

  • True size

    Bar width in millimetres, SVG and PDF at their real size and PNG with its resolution stored – so the size is right when printed.

  • No upload

    The barcode is created in your browser. Nothing is stored or sent.

Frequently asked questions
Which barcode type do I need?

For retail products EAN-13 (UPC-A in North America), EAN-8 for small packs, ITF-14 for shipping cartons. For inventory, warehouses and your own numbers with letters, use Code 128 or Code 39.

Do I get an official EAN number here?

No. The generator only draws the barcode. Numbers for retail are issued by the GS1 organisation in your country; retailers won’t accept goods with a made-up number.

How large should I print the barcode?

The nominal size for EAN and UPC is 0.33 mm per module (EAN-13 is then about 37 × 26 mm). Below 80 % of that, checkout scanners often fail. Keep the light margin on the left and right free.

Which colours can I use?

Dark bars on a light background – ideally black on white. Many scanners can’t see red or light yellow, and most can’t read light bars on a dark background at all.

Does Code 128 support GS1-128 (with FNC1)?

No, the generator creates standard Code 128 from printable ASCII characters and switches to the compact digit mode automatically. GS1-128 with application identifiers is not included.

Is my data uploaded?

No. The barcode is created entirely in your browser.
