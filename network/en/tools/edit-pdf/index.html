Edit a PDF

Add text to your PDF, tick boxes, highlight – right on the page, with a tap.

  • Stays on your device
  • No limits
  • No watermark
  • No account
How can I check that nothing is uploaded?

Your files are processed in this browser tab. This page has no function that sends files to a server, and its security rules (Content Security Policy) forbid connections to other servers.

Check it yourself: load this page, then switch on flight mode or disconnect Wi-Fi and run the tool. It still works – because everything happens on your device.

How it works

  1. Choose your PDF

    Select the PDF you want to edit – a form, a contract, a worksheet.

  2. Edit on the page

    Pick a tool at the top and tap the page: text, tick, date or highlight. Drag items into place with your finger and resize them by their handles. “Undo” takes back any step.

  3. Save

    Tap “Save”. Your changes are written into the PDF – download it or share it right away.

Why FaLe?

  • Change text

Frequently asked questions

Are my files uploaded?

No. You edit the PDF entirely in your browser. Especially with contracts and forms containing personal data, everything stays on your device.

Can I change existing text directly?

With “Change text” you tap a line: it is covered in white and you type the new text on top. The original text stays in the file underneath the cover. The font is matched as closely as possible but may differ slightly.

Is “White-out” secure redaction?

No. White-out only places a box over the content – it stays in the file underneath and can be copied out. For confidential data you need a real redaction tool.

Which characters can I type?

The built-in PDF fonts cover Western European characters, including accents and €. Other characters are replaced – the tool tells you which ones while you type.

Can I edit several pages?

Yes. Use the arrows or swipe on an empty area to go to the next page. All changes on all pages are saved together.

Can the changes be edited later?

They are written into the page so they look the same in every program. If you want to change something later, it is best to edit the original file again.
