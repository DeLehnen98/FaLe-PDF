Add page numbers to a PDF

Number your pages: tap where the number should go – the preview shows the result right away.

  • Stays on your device
  • No limits
  • No watermark
  • No account
How can I check that nothing is uploaded?

Your files are processed in this browser tab. This page has no function that sends files to a server, and its security rules (Content Security Policy) forbid connections to other servers.

Check it yourself: load this page, then switch on flight mode or disconnect Wi-Fi and run the tool. It still works – because everything happens on your device.

Good to know

How it works – step by step

  1. Choose your PDF

    Select the PDF that should get page numbers. If it has a password, you type it right on the file.

  2. Pick position and format

    Tap one of the nine spots in the preview, for example bottom centre. Choose the format, the first number and whether to skip the cover. Swipe through the pages to check each one.

  3. Add and save

    Tap “Add page numbers”. Download the new PDF, share it or make it smaller right away.

Why FaLe?

  • See it before you save

    The preview shows the real page with the number in the chosen font, size and colour – on every page you swipe to.

  • Covers and appendices handled

    Skip the first pages, number only a range or start at any number. Roman numerals and custom text such as “Annex B – 3” work, too.

  • Right on rotated pages

    Landscape pages, rotated scans and cropped pages get the number where you see it – not somewhere on the edge of the original page.

  • Made for binding

    With “Mirror” the number switches sides on even pages, so it is always on the outside of a printed booklet.

Frequently asked questions
Are my files uploaded?

No. The page numbers are added entirely in your browser. You can check this yourself: load the page, switch on flight mode and number your PDF – it still works.

How do I leave the cover page without a number?

Under “Which pages?” choose “Skip the first pages” and enter how many. The first numbered page gets the value of “First number” – if it should show 2, set that to 2.

Does the text of my PDF stay searchable?

Yes. Pages are not turned into images. The number is added as real text and everything else stays as it was.

Which characters can I use?

The built-in PDF fonts cover Western European characters. Other characters in a custom text are replaced – the tool shows you which ones before you save.

What happens with password-protected PDFs?

You type the password right on the file. The numbered PDF is protected again with the same password.
