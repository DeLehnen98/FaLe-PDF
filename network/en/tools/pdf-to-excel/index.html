Convert PDF to Excel

Get tables from invoices, bank statements or reports into a spreadsheet.

  • Stays on your device
  • No limits
  • No watermark
  • No account
How can I check that nothing is uploaded?

Your files are processed in this browser tab. This page has no function that sends files to a server, and its security rules (Content Security Policy) forbid connections to other servers.

Check it yourself: load this page, then switch on flight mode or disconnect Wi-Fi and run the tool. It still works – because everything happens on your device.

Good to know

How it works – step by step

  1. Choose a PDF

    Pick a PDF with tables, for example an invoice, a price list or a bank statement.

  2. Choose settings

    Tables only or the whole page, everything on one sheet or one sheet per page, as XLSX or CSV.

  3. Check and save

    The preview shows the detected tables. Download the file or share it right away.

Why FaLe?

  • No upload

Frequently asked questions
How does the tool find tables?

By how the text is aligned: lines at the same height become table rows, vertical gaps between columns become column borders. No ruling lines are needed in the PDF.

What if no table is found?

Then all text of the pages is taken over – each line a row, with columns where the text lines up. You can also pick this directly with “Whole page”.

Does it work with scanned PDFs?

No, scans contain only images without text. They need text recognition (OCR) first, for example in the FaLe PDF app.

When is CSV better than XLSX?

CSV is plain text any program can read – good for importing. XLSX keeps number formats, the bold header row and several sheets.

Are my files uploaded?

No. The tables are read in your browser.
