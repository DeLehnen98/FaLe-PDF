Your files are processed in this browser tab. This page has no function that sends files to a server, and its security rules (Content Security Policy) forbid connections to other servers.

Check it yourself: load this page, then switch on flight mode or disconnect Wi-Fi and run the tool. It still works – because everything happens on your device.

Good to know

How it works – step by step

  1. Enter your Wi-Fi

    Type the network name (SSID) exactly as it appears on your phone, plus the password and the security – usually WPA.

  2. Pick card or image

    The card (PDF) has the code, network name and password for printing – one A6 card or four on A4. As a PNG you can send the code by messenger.

  3. Save and test

    Save the file and scan the code once with your phone before you put the card out.

Why FaLe?

  • Card with plain text

    Laptops, TVs and consoles often can’t scan. So the card also shows the network name and password readably – in a typeface where l, 1, O and 0 look different.

  • Special characters handled

    Characters like ; , : or quotes in the network name or password break the code in some generators. FaLe escapes them correctly and reads every code back to check it.

  • Your password stays with you

    The code is made in your browser. Network name and password are neither sent anywhere nor stored.

Frequently asked questions
Does the Wi-Fi QR code work on iPhone and Android?

Yes. Current iPhones and Android phones recognise Wi-Fi codes right in the camera app and offer to connect.

What if connecting doesn’t work?

Usually the network name isn’t exact – upper and lower case and spaces count. Also check the security: for WPA2 and WPA3 choose “WPA”.

Does the code change when I change the password?

Yes. The password is inside the code. After a change, simply make a new card.

Is it safe to put the password up as a QR code?

Anyone who scans the code can read the password. Only put it where you’d tell people the password anyway – a separate guest network on your router is ideal.

What is a hidden network?

A Wi-Fi whose name doesn’t show up in the list. Only tick the box if your router really hides the name – otherwise connecting can take longer.
