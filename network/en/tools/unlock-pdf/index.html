Remove a PDF password

Remove the password and restrictions of your own PDFs – right in your browser.

  • Stays on your device
  • No limits
  • No watermark
  • No account
How can I check that nothing is uploaded?

Your files are processed in this browser tab. This page has no function that sends files to a server, and its security rules (Content Security Policy) forbid connections to other servers.

Check it yourself: load this page, then switch on flight mode or disconnect Wi-Fi and run the tool. It still works – because everything happens on your device.

How it works

  1. Choose your PDF

    Select one or more protected PDFs. You immediately see how each file is protected.

  2. Enter the password

    If a file needs a password to open, type it right on the file. Pure print or copy restrictions need no password.

  3. Unlock and save

    Tap “Unlock”. You get the same PDF without a password and without restrictions.

Why FaLe?

  • Shows what is protected

    Before unlocking you see the encryption, password and restricted permissions of each file.

  • Content stays the same

    Text, images, links, bookmarks and form fields stay as they are – only the encryption is removed.

  • No upload

    File and password stay in your browser tab. Nothing is sent or stored.

  • Several files at once

    Unlock several PDFs in one go and download them together as a ZIP.

Frequently asked questions

Am I allowed to remove a PDF’s protection?

Only use the tool for documents that are yours or that the owner has allowed you to unlock. Protection is often set on purpose – respect it for other people’s documents.

Can the tool crack a forgotten password?

No. For a PDF with a password to open you need to know the password. Only restrictions like print or copy locks can be removed without a password, because such files can be opened anyway.

Are my files uploaded?

No. Everything happens in your browser. The password is only used in this tab and never stored.

Which encryption types are supported?

The usual PDF encryption types: AES-256, AES-128 and the older RC4 (40 and 128 bit). Very rare methods, such as certificate-based encryption, are not supported – you will get a message then.

Can I protect the PDF again afterwards?

Yes. With “Protect PDF” you encrypt it with a new password, for example after editing it.
