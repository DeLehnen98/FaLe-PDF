Process many PDFs at once

Choose all files and a recipe – your browser does the rest, file by file.

  • Stays on your device
  • No limits

How can I check that nothing is uploaded?

Your files are processed in this browser tab. This page has no function that sends files to a server, and its security rules (Content Security Policy) forbid connections to other servers.

Check it yourself: load this page, then switch on flight mode or disconnect Wi-Fi and run the tool. It still works – because everything happens on your device.

Good to know

How it works – step by step

  1. Choose PDFs

    Drop in as many PDFs as you like. Other file types are simply skipped.

  2. Pick a recipe

    Take a ready-made recipe like “Ready for e-mail” or tick your own steps. The order is set automatically.

  3. Download everything

    Download the results one by one or as a ZIP. Anything that failed is listed in the report.

Why FaLe?

  • No file or hourly limit

    There is no cap on files per day or hour – the only limit is your device’s memory.

  • One broken file stops nothing

    If a file fails, the batch carries on with the next one. The report lists what was skipped and why.

  • Simple instead of scripting

    No actions to wire up: pick a recipe or tick steps, done. Your choice is remembered for next time.

  • Confidential stays with you

    Files are not uploaded. The password for protection stays on your device, too.

Frequently asked questions
How many files can I process at once?

As many as your device can handle. Files are processed one after another so memory doesn’t fill up – hundreds of normal PDFs are fine.

In which order do the steps run?

Always in a fixed, sensible order: remove pages, rotate, flatten, grayscale, watermark, page numbers, compress, remove hidden data and finally the password.

What happens to files that fail?

They are skipped and all others still get done. You get a report file listing every file with its result or the reason.

What about PDFs that already have a password?

Enter the password on the file card and it is included. Without a password it is skipped and named in the report.

How are the finished files named?

Like before by default. With placeholders such as {name}, {nr} and {date} you set your own pattern, for example “{date} {name}”.

Are my files uploaded?

No. Everything runs in your browser. After the first visit the page also works offline.
