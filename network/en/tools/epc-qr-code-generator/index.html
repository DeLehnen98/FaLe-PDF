Good to know

How it works – step by step

  1. Enter the details

    Type the account holder and the IBAN. Amount and reference are optional – without an amount the payer types it in.

  2. Pick a format

    PNG for invoices, websites or messengers, SVG or PDF for print – or the card with all details in plain text, for example at the till of a club party.

  3. Save and test

    Save the code and scan it once with your banking app. You don’t have to send the transfer.

Why FaLe?

  • IBAN is checked

    A transposed digit in the IBAN shows up right away, before the code is printed – via the check digits, as at the bank.

  • By the standard

    The code follows the EPC guideline (version 002): BIC optional, name up to 70 and reference up to 140 characters, amount up to €999,999,999.99. Overlong entries are trimmed instead of breaking the code.

  • No subscription, no expiry

    The transfer details are in the code itself. It works without a detour through someone else’s server and never expires.

  • Stays on your device

    IBAN and name are neither uploaded nor stored.

Frequently asked questions
Which banking apps read EPC QR codes?

Most banking apps in Germany, Austria and many other euro countries – often under “Scan”, “Photo transfer” or “Scan2Bank”. The transfer is only filled in; the payer still sends it.

Do I need the BIC?

Not for transfers within the SEPA area. Leave the field empty if you don’t know it.

Can I create a code without an amount?

Yes. Then the payer enters the amount – handy for donations or tips.

Can I use accented letters in the reference?

The code itself can hold them. Some banks convert them during the transfer. For invoice numbers, letters, digits and hyphens are safest.

Is an EPC QR code safe?

It only holds what a paper transfer slip would. The payer sees all details in their app before sending. Still check stickers in public places before you pay.
