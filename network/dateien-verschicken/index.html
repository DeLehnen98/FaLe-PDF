FaLe PDF

Dateien sicher verschicken – ohne Konto

Datei wählen, Link schicken. Sie wird auf deinem Gerät verschlüsselt – nur wer den Link hat, kann sie öffnen.

Datei verschicken (öffnet in neuem Tab) Mehr über FaLe PDF

Läuft in FaLe PDF im Browser. Nichts installieren, kein Konto – auch nicht für den Empfänger.

So geht’s

  1. Datei wählen

    Jede Art von Datei bis 50 MB – PDF, Fotos, Videos, Tabellen oder ein ZIP-Archiv.

  2. Einstellen

    Wähl, wie lange der Link gilt (1 Stunde, 1 Tag oder 7 Tage) und wie oft die Datei geladen werden darf. Auf Wunsch mit Passwort.

  3. Link schicken

    Per WhatsApp, E-Mail oder QR-Code. Der Empfänger öffnet den Link im Browser und lädt die Datei – ohne Anmeldung.

Was du bekommst

  • Ende-zu-Ende-verschlüsseltDie Datei wird verschlüsselt, bevor sie dein Gerät verlässt. Der Schlüssel steht nur im Link – unser Server kann sie nicht lesen.
  • Kein Konto, keine WerbungWeder du noch der Empfänger müssen sich anmelden. Keine Werbebilder, kein Tracking.
  • Du bestimmst die RegelnAblaufdatum, Download-Limit und Passwort – und du kannst den Link jederzeit selbst löschen.
  • Löscht sich selbstNach Ablauf oder wenn das Download-Limit erreicht ist, wird die Datei automatisch vom Server gelöscht.

Häufige Fragen

Wie groß darf eine Datei sein?

Bis 50 MB pro Datei. Mehrere Dateien packst du am besten vorher in ein ZIP-Archiv.

Was kostet das?

Nichts. Das Verschicken ist kostenlos und ohne Werbung.

Wer kann meine Datei sehen?

Nur wer den Link hat (und das Passwort, wenn du eins gesetzt hast). Der Schlüssel steht im Teil des Links nach dem #, der nie an unseren Server geschickt wird.

Wie lange bleibt die Datei gespeichert?

So lange, wie du wählst: 1 Stunde, 1 Tag oder höchstens 7 Tage – oder bis das Download-Limit erreicht ist. Danach wird sie automatisch gelöscht.

Braucht der Empfänger eine App?

Nein. Der Link öffnet sich in jedem aktuellen Browser auf Handy oder Computer.

Und zwischen meinen eigenen Geräten?

Dafür gibt es in FaLe PDF „Geräte verbinden“: QR-Code scannen und Dateien direkt vom Handy auf den PC schicken.
