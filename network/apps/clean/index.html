FaLe CleanBald verfügbar

Windows aufräumen, ohne Angst zu machen.

FaLe Clean ist ein System-Cleaner für Windows 10 und 11, von Grund auf neu geschrieben. Er zeigt dir genau, was gelöscht wird, verzichtet auf Alarm-Rhetorik und lässt dich vieles wieder rückgängig machen.

Noch nicht zum Download. FaLe Clean läuft gerade auf Test-PCs. Sobald eine Version stabil genug ist, erscheint sie hier – mit Installationsanleitung.

Was FaLe Clean können soll

Der geplante Funktionsumfang, so wie er in der aktuellen Testversion steckt. Bis zum Start kann sich noch etwas ändern.

  • Gesundheitscheck

    • Bewertet deinen PC von 0 bis 100 – mit ehrlichen Empfehlungen statt Alarm
    • Akku-Zustand laut Windows-Akkubericht, Zustand von SSD und Festplatte
    • Virenschutz, Firewall und ausstehende Neustarts auf einen Blick

  • Aufräumen

    • Temporäre Dateien, Browser-Caches (Chrome, Edge, Brave, Opera, Vivaldi, Firefox), Shader-Cache, Absturzberichte
    • Ein Klick auf eine Zeile zeigt genau, welche Dateien gelöscht werden
    • Cookies für ausgewählte Seiten behalten, damit du angemeldet bleibst

  • Speicher verstehen

    • Größte Ordner, Dateitypen und die 100 größten Dateien
    • Doppelte Dateien per Inhaltsvergleich finden – sie wandern in den Papierkorb
    • Alte Installationsdateien im Download-Ordner aufspüren

  • Schneller starten

    • Echte Startzeit deines PCs aus der Windows-Ereignisanzeige
    • Pro Autostart-Eintrag: wie viele Sekunden er den Start laut Windows verzögert
    • Leistungsmodus und Gaming-Modus, die danach alles zurückstellen

  • Programme & Updates

    • Programme deinstallieren und danach nach Resten suchen
    • Veraltete Programme über winget finden und aktualisieren

  • Datenschutz & Automatik

    • Windows-Werbung, Bing-Suche, Copilot, Recall und Telemetrie abschalten – umkehrbar
    • Vorinstallierte Apps wie Candy Crush oder TikTok entfernen
    • Geplante Reinigung über die Windows-Aufgabenplanung

Ob einzelne Funktionen später zu FaLe Plus gehören, entscheiden wir vor dem Start – und schreiben es hier offen hin.

Sicher statt radikal

Vorsichtige Regeln
Temporäre Dateien werden erst gelöscht, wenn sie älter als zwei Stunden sind. Benutzerordner, Windows und Programme werden nie rekursiv geleert.
Rückgängig machen
Verlauf, Cookies, alte Installer und Programmreste kommen 7 Tage in eine Quarantäne und lassen sich mit einem Klick wiederherstellen. Doppelte Dateien landen im Papierkorb.
Keine Überraschungen
Ist ein Browser beim Aufräumen geöffnet, fragt FaLe Clean, bevor er ihn schließt. Keine Pop-ups und keine Werbung in der App.
Bleibt auf deinem PC
Die Oberfläche läuft nur lokal auf deinem Rechner und ist durch einen zufälligen Schlüssel geschützt. FaLe Clean nutzt nur, was Windows selbst mitbringt.

Bewusst weggelassen

Registry-Cleaner
Laut Microsoft bringt das keinen messbaren Nutzen und kann Windows beschädigen.
Eigene Treiber-Datenbank
Geprüfte Treiber kommen über Windows Update unter „Optionale Updates“.
