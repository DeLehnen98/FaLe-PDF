FaLe PDF

FaLe PDF in der Firma einsetzen.

Die Dokumente bleiben auf den Arbeitsplätzen. Ihre IT verteilt FaLe PDF über die Richtlinien von Microsoft Edge oder Google Chrome und kann alles abschalten, was über das Internet geht.

FaLe PDF öffnen (öffnet in neuem Tab)

Was Datenschutz und IT wissen wollen

Verarbeitung auf dem Gerät
Anzeigen, Ausfüllen, Unterschreiben, Schwärzen, Texterkennung, Komprimieren und Umwandeln laufen im Browser auf dem jeweiligen PC. Dabei werden keine Dokumente auf unsere Server geladen.
Ohne Konto und Lizenzschlüssel
Keine Anmeldung, keine Benutzerverwaltung, keine Seats. FaLe PDF ist kostenlos.
Offline nutzbar
Nach dem ersten Start funktioniert FaLe PDF auch ohne Internetverbindung.
Online nur auf Wunsch
Nur drei Funktionen gehen über das Internet: Cloud-KI (nur mit Einwilligung), Brief per Post und Fax sowie verschlüsseltes Teilen. Jede lässt sich zentral abschalten (siehe unten).
Kein Tracking
Keine Analyse-Tools und keine Werbebanner – Details in der Datenschutzerklärung.
Wo die Dateien liegen
In der Ablage von FaLe PDF im Browser-Profil der jeweiligen Person. Über „Speichern“ landen Ergebnisse als normale Datei im gewünschten Ordner, auch auf Netzlaufwerken.

So verteilen Sie FaLe PDF

Ohne Installationspaket: Microsoft Edge und Google Chrome installieren FaLe PDF über eine Richtlinie auf allen PCs (Gruppenrichtlinie, Intune oder ein anderes MDM). Die Richtlinien gelten für Windows und macOS.

  1. Auf allen PCs installieren

    Richtlinie WebAppInstallForceList (Edge: „Configure list of force-installed Web Apps“) mit diesem Wert setzen. FaLe PDF erscheint dann als eigenes Programm im Startmenü und auf dem Desktop.

    [{"url": "https://pdf.fale.network/app/", "default_launch_container": "window", "create_desktop_shortcut": true}]

  2. Online-Funktionen abschalten (optional)

    Legen Sie diese Datei auf einen eigenen Server (zum Beispiel im Intranet). false schaltet die Funktion ab: cloudAi = Cloud-KI, post = Brief per Post und Fax, cloudShare = verschlüsseltes Teilen und Übertragen. Die Personen sehen dann unter „Ich“ den Hinweis „Von deiner Firma eingestellt“.

    { "cloudAi": false, "post": false, "cloudShare": false }

  3. Datei mit FaLe PDF verbinden

    Richtlinie ManagedConfigurationPerOrigin mit der Adresse der Datei setzen. Das wirkt nur für Web-Apps, die wie in Schritt 1 installiert wurden. Ändern Sie den Hash, wenn sich die Datei ändert.

    [{"origin": "https://pdf.fale.network", "managed_configuration_url": "https://intranet.example.com/fale-pdf.json", "managed_configuration_hash": "<SHA-256 der Datei>"}]

  4. PDFs per Doppelklick öffnen

    Nach der Installation steht FaLe PDF unter „Öffnen mit“ zur Auswahl. Als Standard-App für PDFs legen Sie es in den Windows-Einstellungen unter „Standard-Apps“ fest.

E-Rechnung

FaLe PDF öffnet XRechnung- und ZUGFeRD-Rechnungen und zeigt sie lesbar an – offline. Werkzeuge legen ihr Ergebnis als neue Datei in der Ablage an, die Rechnung selbst bleibt dort erhalten. Für die Aufbewahrung gilt: die Original-Rechnung mit den Rechnungsdaten (XML) unverändert archivieren.

Häufige Fragen aus der IT

Wie kommen Updates?

Wie bei jeder Web-App: Beim nächsten Start lädt FaLe PDF die neue Version im Hintergrund. Es gibt keinen Installer, der Einstellungen überschreibt.

Läuft FaLe PDF auf Terminalservern und Citrix?

FaLe PDF läuft überall, wo ein aktueller Edge oder Chrome läuft. Die Ablage von FaLe PDF liegt im Browser-Profil der Person auf dem jeweiligen Rechner; Dokumente, die auf jedem Arbeitsplatz verfügbar sein sollen, speichern Sie wie gewohnt auf einem Netzlaufwerk.

Welche Browser werden unterstützt?

Aktuelle Versionen von Microsoft Edge und Google Chrome; die zentrale Verteilung über Richtlinien funktioniert mit diesen beiden. Firefox und Safari öffnen FaLe PDF ebenfalls.

Gibt es FaLe PDF im Microsoft Store?

Bald. Bis dahin installieren einzelne Personen FaLe PDF direkt aus dem Browser und Firmen über die Richtlinie oben.
