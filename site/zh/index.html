常见问题

FaLe PDF 真的免费吗？

是的。所有 PDF 和办公功能都免费，无需订阅，也没有水印。只有可选的云端 AI 每天有免费额度。

我的文件会被上传吗？

不会。你的文件在你的设备上处理和保存。只有当你主动使用云端 AI、通过链接分享或同步时，才会有内容离开你的设备——而且是加密的，或者只有你选定的文字。

可以离线使用吗？

可以。除云端 AI、分享和传输外，其他一切功能无需联网。

我可以把 FaLe PDF 安装到电脑上吗？

可以。在上方的“适用于 Windows 和 Mac”中点击“下载”，然后确认“安装”。在 Windows 上请使用 Edge 或 Chrome，在 Mac 上可使用 Safari、Chrome 或 Edge。FaLe PDF 很快也会上架 Microsoft Store。

我可以打开哪些文件？

PDF、Word（DOCX）、Excel（XLSX、CSV）、PowerPoint（PPTX）、文本、Markdown 和图片。
