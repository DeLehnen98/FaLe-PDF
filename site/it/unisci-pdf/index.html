Come si fa

  1. Scegli i file Apri “Unisci” e tocca “Aggiungi documenti”.
  2. Stabilisci l’ordine Trascina i file al posto giusto o usa le frecce.
  3. Unisci Tocca “Unisci”: il nuovo PDF è subito nei tuoi file.

Domande frequenti

Quanti PDF posso unire?

Quanti ne riesce a gestire il tuo dispositivo. Non c’è un limite artificiale.

Posso lasciare fuori alcune pagine?

Sì. Con “Organizza pagine” elimini, ruoti o riordini le pagine prima o dopo l’unione.

Il testo resta selezionabile?

Sì. Le pagine vengono riprese invariate, quindi il testo resta selezionabile e ricercabile.
