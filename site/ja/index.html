Windows・Mac 向け

FaLe PDF を、ふつうのプログラムのようにパソコンへインストールできます。専用のアイコンとウィンドウで、インターネットがなくても使えます。無料、アカウント不要、インストーラーのファイルも不要です。

  1. 「ダウンロード」をクリックします。 ブラウザーで FaLe PDF が開きます。
  2. 「インストール」を確認します。 ブラウザーが、一度だけ確認します。
  3. これで完了です。 次回からは、スタートメニュー（Windows）または Dock（Mac）から FaLe PDF を起動できます。
ダウンロードWindowsMicrosoft Store – 近日公開

Windows では Edge か Chrome がおすすめです。ダブルクリックで PDF が開くようになります。Mac では、Safari（macOS 14 以降：「ファイル」›「Dock に追加…」）、Chrome、Edge が使えます。

こんなことが片付きます

たくさんのツールを順番にたどる必要はありません。みなさんが実際にアプリを開く目的に、そのまま応えます。

  • 賃貸契約書に署名するフォームに入力し、署名を一度書けば、あとはタップするだけで配置できます。
  • 領収書や手紙を取り込む端の自動検出と文字認識つきのスキャナーで、オフラインでも使えます。
  • 解約の通知を送る携帯電話、電気・ガス、ジムなどの文例が用意されていて、1 分で完成します。
  • 応募書類をまとめるテンプレートから履歴書を作り、志望動機書や証明書と一緒に 1 つの PDF にまとめます。
  • 役所に書類を提出する圧縮、PDF/A への変換、機密部分の墨消しができます。
  • 請求書や見積書を書く計算してくれるテンプレートで、PDF、Word、Excel ファイルとして作れます。

よくある質問

FaLe PDF は本当に無料ですか？

はい。PDF とオフィスの機能はすべて無料で、サブスクリプションも透かしもありません。無料の 1 日の利用枠があるのは、任意のクラウド AI だけです。

ファイルはアップロードされますか？

いいえ。ファイルは、お使いの端末上で処理・保存されます。端末の外に出るのは、クラウド AI を自分で使うとき、リンクで共有するとき、同期するときだけで、その場合も暗号化されるか、選んだテキストだけです。

オフラインでも使えますか？

はい。クラウド AI、共有、転送を除く、すべての機能がインターネットなしで動作します。

パソコンに FaLe PDF をインストールできますか？

はい。上の「Windows・Mac 向け」で「ダウンロード」をクリックし、「インストール」を確認してください。Windows では Edge か Chrome、Mac では Safari、Chrome、Edge で使えます。FaLe PDF は、まもなく Microsoft Store にも登場します。

どんなファイルを開けますか？

PDF、Word（DOCX）、Excel（XLSX、CSV）、PowerPoint（PPTX）、テキスト、Markdown、画像です。
