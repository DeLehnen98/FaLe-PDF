PDF を結合する

請求書、スキャンした書類、章ごとのファイルなどを、好きな順番でひとつの PDF にまとめられます。

PDF を結合

使い方

  1. ファイルを選ぶ 「結合」を開き、「ドキュメントを追加」をタップします。
  2. 順番を決める ファイルを正しい位置までドラッグするか、矢印で動かします。
  3. 結合する 「結合」をタップします。新しい PDF がすぐにファイルに保存されます。
PDF を結合

FaLe PDF が選ばれる理由

  • アップロード不要ファイルは端末の中で結合されます。機密性の高い書類も手元から出ません。
  • 大きなファイルも快適数百ページあってもすばやく処理でき、アプリが固まることもありません。
  • そのまま次の作業へ結合後は、圧縮、署名、共有までひとつのアプリで続けられます。

よくある質問

いくつの PDF を結合できますか？

端末が処理できる範囲であれば、いくつでも結合できます。人為的な上限はありません。

特定のページだけ外せますか？

はい。「ページを整理」で、結合の前でも後でも、ページの削除、回転、並べ替えができます。

文字は選択できるままですか？

はい。ページはそのまま取り込まれるので、文字は選択も検索もできます。

料金はかかりますか？

いいえ。結合は無料で、透かしもアカウントも不要です。

ほかにもできること

  • PDF に署名する
  • PDF フォームに入力する
  • PDF を編集する
  • PDF を圧縮する
  • スマホで書類をスキャンする
  • PDF を Word に変換する
  • 行政機関のフォーム（XFA）を開いて入力する
