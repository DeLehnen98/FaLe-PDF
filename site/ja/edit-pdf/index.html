PDF を編集する

文字や画像を追加したり、既存の文字を直したり、一部を隠したり。PDF の上で直接できます。

PDF を編集

使い方

  1. PDF を開く PDF を開き、「PDF を編集」を選びます。
  2. 変更する 「テキスト」で新しい文字を書き、「置換」で既存の文字をタップして直し、「画像」で写真やロゴを入れます。
  3. 保存する 「保存」をタップします。新しい版がファイルに保存され、元のファイルはそのまま残ります。
PDF を編集

FaLe PDF が選ばれる理由

  • 既存の文字を直せます「置換」はその場所のフォント、大きさ、色を引き継ぐので、直した部分が自然になじみます。
  • 文字の設定が簡単大きさは A− と A+、太字、色も、メニューを探し回らずに変えられます。
  • 透かしなし他では有料プランでしか使えない機能にも、ここでは透かしは入りません。

よくある質問

古い文字は本当に消えますか？

置換では、古い文字は上から覆われます。ファイルから確実に消したい機密部分には、「墨消し」を使ってください。

画像やロゴを入れられますか？

はい。JPG と PNG に対応しています。指やマウスで移動したり大きくしたりできます。

オフラインでも使えますか？

はい。一度開いたあとは、インターネットがなくても編集できます。

元のファイルは残りますか？

はい。新しい版が保存されます。ご希望なら元のファイルを置き換えることもできます。

ほかにもできること

  • PDF に署名する
  • PDF フォームに入力する
  • PDF を結合する
  • PDF を圧縮する
  • スマホで書類をスキャンする
  • PDF を Word に変換する
  • 行政機関のフォーム（XFA）を開いて入力する
