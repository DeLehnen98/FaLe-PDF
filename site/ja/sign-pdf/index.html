PDF に署名する

指やマウスで署名を書いて、タップひとつで PDF に入れられます。契約書、申込書、委任状などに使えます。

今すぐ PDF に署名

使い方

  1. PDF を開く FaLe PDF で PDF を開き、「入力と署名」を選びます。
  2. 署名を書く 「署名」をタップして、一度だけ書きます。FaLe が覚えているので、次回はそのまま使えます。
  3. 配置して保存 線をタップし、「大きく」または「小さく」で大きさを合わせて、「保存」をタップします。
今すぐ PDF に署名

FaLe PDF が選ばれる理由

  • ファイルは手元に残ります署名も書類も端末の中で処理されます。何もアップロードされません。
  • 署名だけではありませんテキスト、日付、チェック、イニシャル、オリジナルのスタンプも同じように簡単に入れられます。
  • 契約不要署名は無料で、これからも無料です。透かしもアカウントもありません。

よくある質問

この署名に法的効力はありますか？

入れるのは簡易な電子署名です。紙に署名するのと同じことを、デジタルで行うイメージです。日常的な書類の多くはこれで十分です。法律で特別な方式（たとえば適格署名）が求められる場合は、その方式が必要です。

署名は保存されますか？

端末の中にだけ保存されます。次回、タップひとつで入れられるようにするためです。いつでも削除できます。

パソコンでも使えますか？

はい。FaLe PDF はブラウザーで動き、Windows と Mac にはアプリとしてインストールもできます。パソコンでは、マウスやタッチパッドで書きます。

フォームの入力欄にも入力できますか？

はい。PDF に入力欄があれば、同じ手順で入力してから署名できます。

ほかにもできること

  • PDF フォームに入力する
  • PDF を編集する
  • PDF を結合する
  • PDF を圧縮する
  • スマホで書類をスキャンする
  • PDF を Word に変換する
  • 行政機関のフォーム（XFA）を開いて入力する
