Untuk Windows dan Mac

Instal FaLe PDF di komputer Anda – seperti program biasa: dengan ikon sendiri, jendela sendiri, dan dapat dipakai tanpa internet. Tanpa akun.

  1. Klik “Unduh”. FaLe PDF terbuka di browser Anda.
  2. Konfirmasi “Instal”. Browser Anda bertanya sekali saja.
  3. Selesai. Mulai sekarang Anda membuka FaLe PDF dari menu Start (Windows) atau Dock (Mac).
UnduhProgram Windows (Setup.exe)WindowsMicrosoft Store – segera hadir

Di Windows dengan Edge atau Chrome – lalu PDF terbuka dengan klik dua kali. Di Mac dengan Safari (macOS 14 atau lebih baru: di menu File Safari pilih “Add to Dock”), Chrome, atau Edge. Untuk Windows juga ada program yang dapat diinstal (Setup.exe): saat pertama kali dijalankan, Windows mungkin bertanya sekali – klik “Informasi lebih lanjut”, lalu “Tetap jalankan”.

Yang bisa Anda selesaikan

Bukan tumpukan alat yang harus diklik satu per satu: inilah hal-hal yang membuat orang membuka aplikasi ini.

  • Tandatangani perjanjian sewaIsi formulir, gambar tanda tangan Anda sekali, lalu tempatkan dengan sekali ketuk.
  • Pindai kuitansi dan suratPemindai dengan deteksi tepi dan pengenalan teks – juga saat offline.
  • Kirim surat pemutusan kontrakSurat siap pakai untuk telepon, energi, pusat kebugaran, dan lainnya dalam semenit.
  • Susun lamaran kerjaCV dari template, surat lamaran, dan sertifikat digabung menjadi satu PDF.
  • Kirim dokumen ke instansiKompres, konversi ke PDF/A, sensor bagian yang rahasia.
  • Tulis faktur atau penawaranTemplate yang menghitung sendiri – sebagai file PDF, Word, atau Excel.

Pertanyaan

Apakah file saya diunggah?

Tidak. File Anda diproses dan disimpan di perangkat Anda. Hanya jika Anda sengaja memakai AI cloud, berbagi lewat tautan, atau sinkronisasi, ada sesuatu yang keluar dari perangkat Anda – terenkripsi, atau hanya teks yang Anda pilih.

Apakah bisa dipakai offline?

Ya. Semuanya berfungsi tanpa internet, kecuali AI cloud, berbagi, dan transfer.

Bisakah saya menginstal FaLe PDF di komputer?

Bisa. Di bagian “Untuk Windows dan Mac” di atas, klik “Unduh” lalu konfirmasi “Instal”. Di Windows ini berfungsi dengan Edge atau Chrome, di Mac dengan Safari, Chrome, atau Edge. FaLe PDF juga akan segera hadir di Microsoft Store.

File apa saja yang bisa saya buka?

PDF, Word (DOCX), Excel (XLSX, CSV), PowerPoint (PPTX), teks, Markdown, dan gambar.

Apakah ada iklan?

Di versi browser tidak ada. Di aplikasi Android, banner kecil berlabel muncul di halaman utama – tidak pernah di dalam dokumen, alat, atau editor. FaLe Pro menghilangkan banner. Anda juga bisa menonton video opsional untuk mendapat permintaan AI tambahan.

Coba sekarang juga

Versi browser berjalan tanpa menginstal apa pun – di ponsel maupun di komputer Anda.
